# Atelier

A fast, local-first academic desktop application for Canvas LMS.

Canvas is essential for modern coursework, but the standard web experience is often bogged down by multi-level menus, slow page loads, and fragmented browser tabs.
Atelier moves your academic workflow out of the browser and into an intentional, high-performance desktop application. Built with Electron and designed with a local-first architecture, Atelier continuously synchronizes with the Canvas REST API to cache your entire course load directly on your computer, delivering instantaneous search, offline study capabilities, and a clutter-free study environment.

## Key Features
- Complete Coursework Hub
  Consolidate course announcements, assignment briefs, rubrics, module documents, and grades into a single, cohesive desktop view.
- Local-First Architecture & Offline Access
  Course materials and data are stored locally on your device. Read through lecture notes, review assignment prompts, and consult syllabi without waiting on web page reloads or an active internet connection.
- Deep Local Search
  Quickly index and search across syllabi, course content, assignment descriptions, and personal notes without clicking through complex web module trees.
- Integrated LLM Intelligence
  Synthesize dense readings, query your course syllabus, and break down multi-step assignment prompts into clear, actionable study tasks.
- Unified Calendar & Inbox
  Keep track of upcoming deadlines, exams, and lecture events alongside a native interface for Canvas messaging and correspondence.
- Built-in Notebooks
  Keep contextual markdown notes alongside lecture files and rubrics without switching between external applications.
