Quick Setup Guide

  1. 1
    Open Canvas Portal Log in to your school's Canvas web portal in your web browser.
  2. 2
    Go to Settings Click Account in the left sidebar, then select Settings.
  3. 3
    Find Approved Integrations Scroll down to the Approved Integrations section.
  4. 4
    Generate New Token Click + New Access Token, enter a purpose (e.g. "Atelier"), select an expiration date, and generate.
  5. 5
    Paste & Connect Enter your school's Canvas instance URL (e.g. canvas.harvard.edu), paste your token string into the form on the left, and connect.

Canvas API Specification Reference

Announcements API

GET /api/v1/announcements?context_codes[]=course_<id>

Documented in canvas_docs.pdf (page 110): Fetches course broadcasts and announcements.

Modules API

GET /api/v1/courses/<id>/modules?include[]=items&include[]=content_details

Returns structured learning units, prerequisites, and course content items.

Assignments & Grades API

GET /api/v1/courses/<id>/assignments?include[]=submission&order_by=due_at

Returns course deliverables, points, due dates, student submission states, and computed scores.
